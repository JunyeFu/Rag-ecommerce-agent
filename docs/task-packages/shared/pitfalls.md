# V2 共享易错点

## 仓库与证据

- 旧仓是只读输入。禁止 reset、clean、宽泛暂存、覆盖、移动、自动提交或推送。
- 删除、未跟踪文件和未纳入新方案的设计资产仍属于用户资产。
- 当前源码、Git、运行态和命名验证器高于 README、截图、历史完成数字和演示视频。
- `complete` 只表示任务包本地范围完成；contract、integration、provider sandbox、LIVE、真机、法律和发布不得混报。

## Agent

- 固定路由图、提示链或多个 LLM 角色不自动构成 Agent；必须有类型化工具、状态、护栏、恢复和验证。
- 首版采用单管理 Agent。不要为展示“Agent 化”提前建设多 Agent 网络。
- 生产 API、内部评测、语音和图片不得各自复制一套编排器。
- 每轮必须有工具和重规划预算；超限后停止并解释，不允许无限循环。
- 不持久化未经同意的用户偏好；记忆必须可查看、修改和删除。

## 商业真相与 RAG

- Product、Variant、Merchant、Offer 和 OfferQuote 不得合并成一个宽泛商品对象。
- LLM 不计算或补全价格、原价、销量、库存、运费、保障、店铺身份或评分。
- 外部商品描述、网页和 Feed 都是不可信输入，不能成为系统指令或工具参数权威。
- Qdrant 是派生投影，不是商品或报价事实源；索引可重建且不得双写。
- 低置信度实体匹配不得合并最低价；规格不一致必须并列展示。
- 过期报价只能显示最后采集时间，不能宣传实时、最低价或有货。

## 连接器与深链

- 连接器 fixture 通过不证明 live 主体授权、价格正确或联盟链接可结算。
- 禁止绕过验证码、登录、风控、robots、访问控制或站点条款获取数据。
- URL 必须经过 scheme、host、redirect 和商品身份校验，防止 SSRF 与开放重定向。
- 赞助与佣金不得静默影响自然排序；必须披露并在 Trace 中记录。

## Android 与运营台

- 不恢复 Explore 随机地图、Compare 一级标签、支付密码、本地假客服或模拟订单动作。
- 新野兽派只作为品牌点缀；价格、证据、风险和主操作要优先可读性与可访问性。
- 编译、lint、Benchmark UP-TO-DATE 不等于 instrumentation、真机 HTTPS 或联盟深链通过。
- 运营台 Trace 不输出思维链、密钥、授权响应或完整用户敏感输入。

## 安全与发布

- `.env`、签名文件和本地属性只记录必须忽略，不读取或复制内容。
- 测试不得输出密钥、签名口令、真实手机号、地址或本机用户媒体路径。
- 未取得联盟合同、法律审核、渗透测试、真实评测和正式签名前，不得宣称商业可用。
