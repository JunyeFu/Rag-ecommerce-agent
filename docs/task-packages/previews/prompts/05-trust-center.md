# 05 我的与信任中心预览提示词

## 图像生成提示词

Create one production-quality 390×844 Android app-content-only UI screen. Continue the exact confirmed kinetic editorial-tech visual language: warm bone paper, oversized near-black Chinese typography, acid-lime active accents, deep emerald technical marks, engineering grid lines, halftone fields and registration symbols. This is the “我的” primary destination of a RAG shopping Agent, designed as a transparent system passport rather than a conventional e-commerce profile page.

At the top show the oversized heading “我的” and an editorial label “运行护照”. Make the main declaration area clearly separate capability evidence from infrastructure connection. Under “模型与数据声明”, show three explicit rows: “模型：确定性 FAKE”, “商品：DEMO_DATASET”, “报价：DEMO_FIXTURE”. Add the plain warning “当前不是 LIVE 环境”. Do not compress these into one generic demo badge.

Below, show “连接状态” as a separate technical rail with exactly three concise states: “API 已连接”, “Worker 就绪”, “事件流 已连接”. Add the note “连接正常不代表 LIVE 报价”. Then show “隐私与授权” with two manageable states: “保存任务历史  已同意” and “匿名质量数据  已关闭”, plus a small action “管理授权”.

Near the bottom, add a restrained destructive section “我的数据” with a single coral-outlined action “删除我的数据” and the explanation “删除任务、决策、待购与相关媒体”. The delete action must be clearly distinct but not visually dominant over the trust declarations. Show “Contract 0.2.0” as a small technical footer. Include the compact native navigation “任务”, “决策”, “我的”, with “我的” active.

Do not show avatar, username profile, membership, points, coupons, order history, customer service, marketing, social features, OAuth login, API keys, secret values, hostnames, local file paths, signing data, fake LIVE capability, phone bezel, status bar, watermark or external brand. Avoid a generic settings list and avoid nested cards; use editorial hierarchy, dividers and technical annotations.

## 交互与状态约定

- 模型模式、商品数据集、报价证据等级和连接状态分别来自运行声明 API，不相互推断。
- “管理授权”读取并更新服务端同意状态；切换结果刷新后保持一致。
- “删除我的数据”先打开不可逆范围确认，确认后调用真实删除链并显示可恢复查询的进行中/完成/失败状态。
- 删除范围覆盖任务、决策、清单、待购、审批、相关媒体和用户可关联投影，不把清空本地界面当作完成。
