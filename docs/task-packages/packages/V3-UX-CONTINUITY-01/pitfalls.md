# 开发易错点

- 未知不等于满足；不扩大报价事实来源。
- 反馈、保存、待购和审批是不同动作；禁止自动批准或跨任务继承任务约束/审批。用户级保存与待购不属于单一任务，不能在任务重置时清除。
- 全局待购必须独立读取商品/用户报价；普通读取不能续期。关闭确认面板不代表 API 已写回，原生测试需等实际数量行并核对持久化。
- 保留用户既有脏改动、失败报告及个人资产；不清空数据库。
- fake/API/unit/原生/真实模型证据分别记录，未验收不得标complete。
- 保存比较的确认选择只持久化在本机DataStore，不包装为服务端或跨设备同步；商品/清单/报价来自当前身份API。打开详情不得用TurnOffers覆盖当前任务报价，普通查看必须fresh=false；只有显式重新询价允许续期。
