## 首屏文案差异

- 概念要求的 `RAG Commerce Ops`、`连接器`、五域导航、`生产预演`、`运营审核员`、来源健康、报价新鲜度、本地证据与外部门禁均保留。
- 实现增加 `非生产`、`reviewer fixture` 和证据时点，用于防止把 fixture 误读为生产态；属于真实性门禁，不是营销文案。
- 概念中的通知与帮助图标未实现，因为当前包没有相应工作流，保留会形成无功能按钮。
- 概念中的品牌官网、价格指数、库存聚合三行未实现，因为当前权威连接器夹具只有淘宝/天猫、京东、拼多多；禁止发明来源和指标。

## 交互核验

- 依次打开五个工作域，均产生正确标题和内容。
- 实体冲突执行“保持分离”后状态变为 `KEPT_SEPARATE`，两个操作按钮禁用。
- 排队本地评测后产生 `QUEUED` 行，证据改为 `pending:runner`，未继承 smoke 的 PASS。
- 发布门禁保持 `LOCAL/INTEGRATION` 与 `LIVE/HUMAN/RELEASE` 分层，明确显示当前不可发布。
- 新浏览器会话控制台为 0 errors、0 warnings。

## 结论

在不发明运营事实与无功能控件的前提下，最终实现与概念的骨架、密度、视觉 token、表格主导容器和右侧详情栏一致；未发现仍需修复的物料、布局或交互偏差。
