# V3-DECISION-WORKBENCH-01 决策比较工作台（小层 03）

## 目标
确认承接推荐结果页“加入对比”的约束导向决策工作台，以 Agent 结论、核心取舍、未满足项和证据帮助用户形成方案。
## 状态
`complete`
## 范围
- 只比较用户从三层推荐栈主动加入的 2 至 3 个候选，并始终绑定原 Mission 约束。
- 首屏优先展示 Agent 结论和关键取舍，再展示候选在降噪、舒适、续航等决策维度的差异。
- 未满足项、风险和证据入口必须直接可见；支持保存方案和加入待购。
- 保留任务、决策、我的全局导航，并以“决策”为当前入口。
## 非目标
- 不实现支付、订单、购物车结算、促销推荐或纯参数表式商城比较。
## 前置依赖
- `V3-EXPERIENCE-CONTROL-01`、`V3-ANDROID-01`。
## 路径所有权
- Android 决策页相关组件及本包预览证据。
## 现状证据
- 小层 01 与 02 已确认；comparison/list/cart API 已接入，当前需要冻结约束导向的信息层级和写操作入口。
## 执行步骤
1. 生图。2. 用户确认。3. 对齐类型化 comparison payload。4. API 驱动保存方案与待购测试。
