# V3-MISSION-WORKBENCH-01 对话后推荐结果栈（小层 01）

## 目标
确认并实现用户在对话中提交需求、Agent 完成分析后出现的全屏纵向推荐结果栈。
## 状态
`complete`
## 范围
- 结果栈固定包含主推荐、次推荐、再次推荐三个按 Agent 排序的类型化候选。
- 首屏完整展示主推荐；向下滚动吸附到次推荐；次推荐可上下切换；再次推荐只能向上返回。
- 每屏只呈现一个推荐框及其匹配、证据、风险、报价状态和必要动作，底部仅露出下一屏入口。
## 非目标
- 不承载对话输入、Mission 约束总览、Agent 分析过程、全局底部导航、商品列表、订单或支付。
## 前置依赖
- `V3-EXPERIENCE-CONTROL-01`、`V3-ANDROID-01`。
## 路径所有权
- `apps/android` 对话后结果路由、纵向推荐 Pager、推荐框及本包预览证据。
## 现状证据
- 用户已选择“编辑实验室”美术方向，并明确本页只属于 Agent 分析完成后的推荐结果。
## 执行步骤
1. 修订 AI 预览。2. 冻结三屏滑动状态机。3. 用户确认。4. 对齐 Compose VerticalPager。5. 模拟器验收。
