# V3-DEMO-PRICE-01 弱权威第三方演示查价

## 目标
增加一个可显式启用的只读第三方沙箱查价入口，为演示外部数据调用提供证据，同时保持项目自有 60 SKU、联盟 LIVE 与商业发布边界不变。

## 状态
`complete`：客户端、单次演示入口、真实沙箱冒烟和本地门禁均已通过；持续免费、目录相关性和价格准确性仍是外部门禁。

## 范围
- 格物知心 HTTPS 沙箱商品搜索。
- `THIRD_PARTY_DEMO` 弱权威证据等级。
- 单次调用、无重试、无 fixture 回退的命令行演示入口。
- 脱敏的真实沙箱冒烟证据。

## 非目标
- 不把第三方商品映射为项目自有虚构 SKU。
- 不参与 RAG 推荐、最低价排序或商业发布证据。
- 不接入下单、结算、售后、用户资料或联盟深链。
- 不承诺免费额度、持续可用性或报价准确性。

- `V3-PORTFOLIO-CLOSE-01`。
- 用户明确允许注册弱权威、小范围、免费沙箱查价 API。

第三方要求付费、扩大写权限、返回结构漂移、目录相关性不足或凭据失效时，停止外部查价并明确显示不可用。
