# V2-DATA-01 旧仓数据种子许可与确定性导出

## 目标

把旧仓商品和评测数据转为可追溯、可验证、无用户数据的 V2 开发种子包。

## 状态

`complete`

## 范围

- 只读导出 287 条商品和 226 条评测种子。
- 生成字段映射、来源/许可台账、SHA-256、统计和数据质量报告。
- 识别图片、品牌、类目、价格、属性和 ground truth 的许可与完整性缺口。
- 将旧单一 price 标记为历史种子字段，不升级为实时 OfferQuote。

## 非目标

- 不导出用户、消息、会话、反馈、购物车、订单、地址、凭据或日志。
- 不把旧商品数据声明为生产目录或商业许可已完成。
- 不直接写入 PostgreSQL 或 Qdrant。

## 前置依赖

- `V2-BASE-00` 的工程和验证入口完成。

## 路径所有权

- `data/seed/`、`evals/seed/`、`docs/data/`。
- `scripts/export_v1_seed.py` 及数据质量测试。

## 现状证据

- 旧仓商品种子 SHA-256、287/100/182 统计和评测 226 条记录在共享业务数据中冻结。
- 旧仓工作树很脏，因此导出必须按明确输入路径只读执行。

## 执行步骤

1. 定义 V2 seed schema 和禁止字段列表。
2. 校验旧输入哈希，哈希漂移则停止并重新审计。
3. 确定性导出商品、评测和允许使用的图片引用。
4. 生成许可台账、统计、重复/缺失/PII/引用完整性报告。
5. 重复执行并确认 byte-for-byte 一致。

## 数据引用

- `../../shared/business-data.json`
- `../../shared/development-data.json`
- `../../shared/pitfalls.md`

## 验收

- [x] 商品与评测输入哈希均与冻结基线一致。
- [x] 两次导出 5 个输出的字节和 SHA-256 完全一致。
- [x] 用户、订单、地址、消息、凭据和 PII 命中数量为 0。
- [x] 每个输出都有来源、许可状态、Schema 版本和生成命令。
- [x] 未获商业许可的数据被隔离为 `development_only`，商业使用标志为 false。

## 回滚

- 删除本包生成的 seed 和报告；不反向修改旧仓数据。

## 停止条件

- 输入哈希漂移、许可来源不明、发现真实 PII 或需要读取 ignored 文件时停止。

## 交接格式

- 结果：导出包 ID、统计和哈希。
- 变更路径：data/seed、evals/seed、docs/data。
- 验证命令与结果：导出重放、Schema、PII 和引用检查。
- 剩余外部门禁：数据商业使用许可。
- 风险与下一包：交给 V2-DOMAIN-01 与 V2-RAG-01。
