# V2-SECURITY-01 Agent工具数据与深链安全闭环

## 目标

完成 Agent 工具、外部商品内容、媒体、用户偏好、运营台和深链的生产前安全闭环。

## 状态

`complete`（本地可自主闭环；生产漏洞、凭据、法律与独立渗透门禁保持阻断）

## 范围

- 建立 Agent 威胁模型：目标操纵、提示注入、工具滥用、记忆污染、数据泄漏和拒绝服务。
- 验证认证、对象所有权、最小权限、速率、幂等、媒体生命周期和用户数据删除。
- 验证 connector SSRF、开放重定向、恶意 host、签名日志和第三方响应注入。
- 实现依赖、容器、secret、SAST、SBOM、许可证和日志脱敏门禁。
- 建立安全事件、撤销连接器和 fail-closed 操作手册。

## 非目标

- 不自行执行未授权外部渗透、凭据轮换、生产流量攻击或历史重写。
- 不把静态扫描 PASS 描述为独立渗透测试或法律批准。
- 不扩大首版工具到支付、退款、订单或任意网页操作。

## 前置依赖

- `V2-API-01`、`V2-ANDROID-01`、`V2-OPS-01` 完成可测试主链。

## 路径所有权

- `docs/security/`、安全测试与策略配置。
- 必要的 agent-runtime、api、connector、Android、ops 安全修复路径。
- CI 安全门禁与 SBOM 输出。

## 现状证据

- 旧 Android 存在演示型本地固定密钥方案，V2 必须彻底移除支付密码能力。
- 商家内容和网页是外部不可信输入，可能诱导 Agent 调错工具或跳转恶意地址。

## 执行步骤

1. 冻结资产、信任边界、攻击路径、风险所有者和发布阈值。
2. 建立提示注入、工具越权、记忆污染、SSRF、redirect、媒体和 RBAC 测试集。
3. 修复发现并加入回归、审计和监控。
4. 生成 SBOM、许可证、SAST、secret、容器和依赖报告。
5. 交付独立渗透与法律审核输入包，不代替外部结论。

## 验收

- [x] 本地安全回归中未授权工具执行、跨用户访问、prompt-driven redirect 和 secret 泄漏为 0。
- [x] 不可信提示不能自授权导航或购物车修改；外部 host、重定向及私网解析结果 fail-closed。
- [x] 内存适配器下媒体、偏好、会话和 Trace 的指定用户删除可验证且不影响另一用户；生产事务删除仍为门禁。
- [x] SBOM、许可证台账、SAST 和 secret 扫描完成；依赖 advisory、候选镜像和法律许可结论 fail-closed。
- [x] 本地安全事件/连接器撤销桌面演练完成；平台侧凭据撤销未执行且保持外部门禁。

## 回滚

- 优先禁用受影响工具、连接器、媒体类型或运营写操作；保留审计并使用最小补丁回滚。

## 停止条件

- 需要读取真实 secret、外部攻击授权不明、法律边界未确定或发现无法本地缓解的 P0 时停止发布链。

## 交接格式

- 结果：威胁模型、已关闭风险和开放 P0/P1。
- 变更路径：security docs/tests/config 与必要修复。
- 验证命令与结果：security regression、SAST、SBOM、secret、container。
- 剩余外部门禁：凭据轮换、法律审核和独立渗透测试。
- 风险与下一包：仅在 P0/P1 关闭后交给 V2-LIVE-01。
