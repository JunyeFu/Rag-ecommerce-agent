# V3-ACTION-APPROVAL-01 审批、询价与安全外跳（小层 04）

## 目标
确认 Agent 在执行可逆写操作、重新询价和打开外部演示商家前使用的原生审批面板，确保动作、影响和证据等级对用户透明。
## 状态
`complete`
## 范围
- 对保存方案、加入/移出待购等可逆写操作提供简版确认；对重新询价并外跳提供增强确认。
- 增强面板明确展示目标商品、将执行的两个步骤、当前证据等级、报价时效、目标域名、不会发生的动作以及取消/确认。
- 用户确认后才创建审批记录并执行工具；重复点击由幂等键收敛。
## 非目标
- 不实现真实支付、订单或自动下单；不把 `DEMO_FIXTURE` 升级为 `LIVE`，也不在确认前预取并打开外部链接。
## 前置依赖
- `V3-INTELLIGENCE-CONTROL-01`、`V3-AGENT-01`、`V3-ANDROID-01`。
## 路径所有权
- Android 审批组件、安全链接解析及本包预览证据。
## 现状证据
- 小层 03 已确认；工具权限、审批 API 与安全链接解析已存在，当前需要冻结高风险动作的用户可见契约。
## 执行步骤
1. 生图。2. 用户确认。3. 对齐审批 API 和工具参数。4. 重放、取消、过期、幂等与安全域名测试。
