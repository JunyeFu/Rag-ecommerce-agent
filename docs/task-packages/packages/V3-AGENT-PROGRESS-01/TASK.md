# V3-AGENT-PROGRESS-01 对话、澄清与公开分析（小层 02）

## 目标
确认推荐结果出现之前，用户提交需求、Agent 必要澄清和可公开分析阶段的 Android 连续对话体验。
## 状态
`complete`
## 范围
- 在任务主入口保留精简对话历史、输入框和任务/决策/我的全局导航。
- 用户提交购买需求后，Agent 只在信息不足时提出一个必要澄清问题；回答必须写回 Mission 约束。
- 分析阶段只公开理解需求、混合检索、核验证据、比较候选四个可验证阶段。
- 分析完成后进入已确认的小层 01 三层纵向推荐结果栈。
## 非目标
- 不展示内部推理、prompt、原始工具参数、隐藏评分、商品卡、推荐排名、报价或营销内容。
## 前置依赖
- `V3-INTELLIGENCE-CONTROL-01`、`V3-AGENT-01`。
## 路径所有权
- Android 任务状态组件、类型化进度事件及本包预览证据。
## 现状证据
- 小层 01 已确认；当前需要冻结其上游对话与公开分析页面，避免结果未完成时提前展示商品。
## 执行步骤
1. 生图。2. 用户确认。3. 对齐 Mission 更新和 progress 事件 reducer。4. 测试澄清、失败、超时和结果页跳转。

## 验收
- [x] 用户确认预览与页面职责。
- [x] 澄清回答真实更新 Mission，进度与事件日志一致。
- [x] 未完成分析时不出现商品推荐，完成后进入小层 01。
- [x] 无思维链，失败、超时和取消状态显式呈现。
## 回滚

## 停止条件

## 交接格式
- 预览、状态映射、用户决策、事件测试、风险。
