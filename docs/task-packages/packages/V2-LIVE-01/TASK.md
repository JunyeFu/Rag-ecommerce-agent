# V2-LIVE-01 真实报价小流量与物理终端验证

## 目标

在已授权环境中验证真实报价、深链、真实模型、故障降级和物理 Android 主链。

## 状态

`blocked`（未获 live 权限；0 请求、0 真机、0 报价抽样）

## 范围

- 启用已授权连接器和模型提供方的小流量配置。
- 运行真实报价、变价、下架、限流、超时、部分站点故障和 discovery 降级。
- 运行文本、语音、图片、多轮、排除、比较、清单、购物车和深链真机场景。
- 抽样对比 connector Quote 与商家落地页，记录采集窗口和误差。
- 记录 p50/p95/p99、错误率、成本、Trace、Android crash/ANR 和运营告警。

## 非目标

- 不代表商家成交、订单履约、退款或长期生产稳定性。
- 不绕过联盟审核、灰度批准、用户同意或生产安全门禁。
- 不自动扩大流量或开启未获批准的站点。

## 前置依赖

- `V2-EVAL-01` 达到离线质量门禁。
- `V2-SECURITY-01` 关闭本地 P0/P1 并形成外部审核输入。

## 路径所有权

- `tests/live/`、`docs/live/`、灰度配置和脱敏运行证据。
- 不修改任务实现逻辑；发现缺陷退回责任包修复。

## 现状证据

- 旧仓仍缺真实提供方评测和物理真机 HTTPS 证据。
- live 权限、真实凭据、设备和商家页面均是本包的外部前置条件。
- V2 本地任务包已形成可交接输入，但 held-out 人工双评为 0/100，外部安全门禁仍开放。

## 执行步骤

1. 记录发布身份、凭据所有者、允许站点、设备、网络和流量上限。
2. 运行连接器、报价抽样和落地页一致性验证。
3. 运行真实模型 Agent 场景和故障注入。
4. 运行物理 Android、TalkBack、弱网、后台恢复和联盟 App/浏览器跳转。
5. 汇总质量、延迟、成本、告警和失败，达到阈值才允许进入发布包。

## 验收

- [ ] 所有 live 请求均使用已批准主体、凭据、域名和流量范围。
- [ ] 活跃连接器报价抽样失配率 < 1%，过期报价误标实时为 0。
- [ ] 首状态 p95 <= 500ms，首有效候选 p95 <= 5s，完整回复 p95 <= 10s。
- [ ] 12 个 Android 核心场景在物理设备 HTTPS 下通过。
- [ ] 故障降级无伪造价格、越权动作、未披露佣金或恶意跳转。
- [ ] 失败与外部不可用均如实记录，没有用静态 PASS 替代。

当前全部验收项保持未勾选；门禁判定见 `../../../live/readiness.json`。

## 回滚

- 立即停止流量、禁用对应连接器/模型版本并回到 fixture 或上一批准版本；保留审计和样本。

## 停止条件

- 授权、凭据、法律、生产环境、设备或安全批准缺任一项即停止；出现 P0 立即终止灰度。

## 交接格式

- 结果：运行 ID、流量范围、通过/失败和报价抽样。
- 变更路径：live tests/docs/config only。
- 验证命令与结果：provider、connector、fault、device、accessibility。
- 剩余外部门禁：商业主体与正式发布批准。
- 风险与下一包：仅满足所有阈值后交给 V2-RELEASE-01。
