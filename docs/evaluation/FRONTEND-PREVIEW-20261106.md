## 可体验的变化

- 浅暗主题采用微明度层级，推荐正文独立滚动，底部比较、保存和待购操作固定；大字号操作区自动排成两行。
- 报价同时匹配商品与规格；到期、回到前台及执行动作时重新判断有效性，发现级和无价报价不参与最低价排序。
- 操作回执在任务、决策及个人页就近呈现；失败及结果未确认保留至处理或关闭。系统返回先处理键盘与弹层，再返回任务。
- 单收藏收起不可执行的比较区，单推荐不提示不存在的下一款；Ops概览、表格、详情和参数按任务层级展示。
