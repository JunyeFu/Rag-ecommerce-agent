# Held-out 双人盲评规则

## 门禁状态

当前为 `BLOCKED_PENDING_DUAL_HUMAN_REVIEW`：100 条已进入盲态队列，0 条完成评审，reviewer 身份、预算和外部盲评工作区尚未冻结。

## 执行规则

- 两位评审独立完成全部 100 条，互不可见标签、说明和模型身份。
- 用例按 blind_token 展示；不得显示 expected、dev/test 结果或调参历史。
- 每条分别标注：任务完成、硬约束、事实依据、工具授权、安全/隐私和表达可用性。
- 一级标签为 `PASS/FAIL/UNSURE`；`FAIL/UNSURE` 必须选原因并写不含 PII 的简短说明。
- 两位标签不同则进入第三人仲裁；原始标签不可覆盖。
- 报告 reviewer 完成率、原始一致率、Cohen's kappa、仲裁数、各原因失败数和 95% 区间。

## 禁止事项

- 不得用 held-out 调 prompt、模型、检索权重、工具策略或规则。
- 不得把 LLM-as-judge 代替任一人工评审。
- 不得把未完成、跳过或无结果样本移出分母。
- 不得把仓库内流程隔离描述为外部加密封存；正式竞赛提交前需要独立封存工作区。
