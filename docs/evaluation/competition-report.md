# Competition V1 当前报告

## 数据结果

- 600 条项目自生成且 query fingerprint 唯一的用例，五类最低数量全部满足。
- dev/test/held-out 为 360/140/100；本地 runner 只消费前 500 条。
- 旧 226 条种子有 223 个唯一 query、3 组重复 query，226 条许可和 gold 均待审，因此从 competition-v1 排除。

## 本地机器证据

- 500 条 reference 构造器全部通过 grader，95% 区间均为 `[1, 1]`；这只验证评测 harness 自洽，不是模型分数。
- 负控被正确判为失败，并保留 outcome、禁用工具、证据、商业事实、HTTP 深链和敏感字段六类失败。
- 旧开发种子的当前 BM25+结构化约束+开发 prior：144 条，Recall@10 `0.944444`、NDCG@10 `0.916780`。
- 去除 prior 后 Recall@10 `0.797454`、NDCG@10 `0.636359`；稀疏 token vector 与 RRF 也未达目标，失败结果完整保留。
