# Agent 商业导购威胁模型 v1

## 资产与信任边界

受保护资产包括用户身份、媒体、会话、偏好、Agent Trace、商业报价、联盟深链、连接器授权、运营写操作和发布门禁。用户输入、商品标题与描述、商家响应、图片/语音识别文本、联盟跳转和浏览器内容一律属于不可信输入；只有版本化策略、类型化工具注册表、服务器身份、授权连接器和签名发布产物属于受控边界。

主信任边界为：Android/运营 Web → API 身份与所有权 → Agent 运行时与工具策略 → RAG/连接器 → 外部平台。开发用 `X-User-ID` 与 `X-Ops-*` 头只用于本地测试，不是生产认证。

## 攻击路径与控制

| 风险 | 典型攻击 | 本地控制 | 当前证据 | 发布条件 |
|---|---|---|---|---|
| 目标操纵/提示注入 | 商品描述要求忽略系统策略、自动购买或跳转 | 十个冻结工具、严格参数模型、工具预算；支付/订单/退款不存在 | Agent 安全回归 | 真实模型红队与人工复核 |
| 工具滥用 | 未批准购物车写入、视觉识别或外部导航 | 风险分级、显式审批、幂等键、replan/tool 上限 | runtime tests | 生产身份和共享限流 |
| 记忆污染 | 外部内容写入长期偏好 | 明示同意才保存；用户删除接口 | store/erasure tests | 生产事务型删除适配器 |
| 数据泄漏 | 跨用户读取媒体、会话或 Trace；日志输出参数/凭据 | owner 检查、公共事件投影、Trace 脱敏、secret scan | API/Ops tests | 独立渗透和日志平台验证 |
| SSRF/开放重定向 | 私网 IP、userinfo、恶意端口、DNS rebinding、跳转换域 | HTTPS 443、精确 host、IDNA、重定向链和已解析 IP 验证 | connector tests | live transport DNS pinning |
| 商业事实伪造 | 把搜索摘要当实时价格或推广链接 | 来源/时间/验证等级；跳转前 requote；变化需确认 | connector/RAG tests | live 联盟授权与抽样核对 |
| 媒体攻击 | MIME 伪造、超限文件、跨用户引用、过期对象 | 魔数、大小、TTL、owner 和删除 | API tests | 对象存储恶意文件扫描 |
| 拒绝服务 | 大输入、无限工具循环、重试风暴、SSE 游标攻击 | 长度/数量上限、限流、熔断、工具预算、游标校验 | unit/integration tests | 网关共享限流与压测 |
| 运营越权 | viewer 修改冲突、伪造评测/门禁 | 开发角色矩阵、写操作幂等、追加审计 | Ops API/browser tests | SSO/RBAC 与持久审计 |
| 供应链 | 依赖投毒、密钥入库、恶意镜像 | 锁文件、wrapper hash、SBOM、模式扫描 | local security gate | CI advisory/container scan 与签名 |

## 风险所有者与阈值

- 产品安全负责 P0/P1 分类、安全回归和外部渗透交接。
- 连接器负责人负责 allowlist、DNS/redirect 传输实现、凭据撤销和平台条款。
- 数据负责人负责保留、删除、许可与数据主体请求。
- 发布负责人只有在 live、人工、法律、漏洞、签名门禁都有当前证据时才能批准。
- 任一未经授权工具动作、跨用户访问、prompt-driven redirect、明文 live secret 或开放 P0/P1 都是发布阻断项。

## 明确不覆盖

本模型不证明生产云网络、KMS、SSO、WAF、对象存储、第三方 SDK、真实联盟平台或模型提供方已经安全；这些只能由对应环境的运行证据关闭。
