# 数据保留与删除矩阵

| 数据 | 本地当前实现 | 删除路径 | 商业环境硬门禁 |
|---|---|---|---|
| 上传图片/音频 | 进程内对象，默认 TTL 24 小时；魔数、大小和 owner 校验 | 单对象删除；确认后的用户数据删除组合器；过期清理 | 对象存储生命周期、恶意文件扫描、备份删除证明 |
| 会话/Turn/运行索引 | owner 隔离；本地内存或 PostgreSQL API 索引 | 内存组合器可删除；API 在未注入事务型适配器时返回 503 | PostgreSQL 跨表事务删除及失败恢复演练 |
| Agent checkpoint/事件/Trace | 可重放；公共事件不输出原始参数 | 内存 store 删除该用户运行元数据、checkpoint、事件与偏好 | 生产数据库删除、日志平台删除/匿名化及法定留存冲突裁决 |
| 用户偏好 | 仅明确同意后保存 | store `delete_user`；用户数据删除 API | 同意记录、撤回同步与备份传播 |
| 运营审计 | 本地追加事件；不允许普通用户修改 | 不随普通用户删除直接销毁；应做不可逆主体假名化 | 法律批准的留存期与主体映射销毁 |
| 商品/报价证据 | 版本化商业事实，不作为用户私有数据 | 按数据许可和来源版本处理 | 平台条款、删除通知与快照合法性 |

`DELETE /v1/users/me/data` 必须携带当前身份以及 `X-Deletion-Confirmation: delete-my-data`。未配置单一事务型生产删除适配器时接口 fail-closed 返回 503，避免把局部删除声明为完整删除。

当前本地组合器只用于确定性测试。它验证媒体、会话索引、运行 checkpoint/Trace 和偏好对指定用户被删除且不影响另一个用户；它不是对象存储、备份、分析日志或 PostgreSQL 生产删除证明。
