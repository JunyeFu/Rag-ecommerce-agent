## 制作约束

- 长模型等待可剪辑，画面须注明“等待过程已剪辑”，旁白不声称实时完成速度。
- 主/次/再次推荐维持纵向浏览，不为拍摄改变产品布局。
- 如旧任务无法再呈现某镜头，用其真实验收录屏并标明验收日期、版本范围；没有素材则留待拍，禁止拼接为同一连续任务。
- 声音保留真实人声的必要片段，隐去测试身份、设备路径、Trace原始标识及个人信息。
- 导出MP4后检查时长、音轨、每一镜头来源及最终源码对应关系，再记录SHA-256；此卡不代替这些检查。
