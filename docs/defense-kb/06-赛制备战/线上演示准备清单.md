```

```

### 降级方案

| 风险 | 预案 |
|------|------|
| 网络不稳 | 使用 `localhost` 直连，避免跨网络 |
| 模拟器卡顿 | 提前测试帧率，关闭动画/特效 |
| LLM API 限流 | 预热几个高频查询到 LRU 缓存（16ms 直出） |
| 设备故障 | 备用手机 + 预装 APK |
| 屏幕共享失败 | 切换到预录视频（docs/submission/拾物演示视频.mp4） |

## 线上应答准备

### 常见线上答辩突发情况

| 情况 | 应对 |
|------|------|
| 评委问 Docker 起不来 | 提前 `docker compose ps` 确认 3 容器 healthy |
| 评委问 API Key 在哪 | "在 .env 中，不与代码一起提交，符合安全规范" |
| 评委要求看代码 | 提前打开 IDE（VS Code），切到关键文件 |
| 评委质疑 AI 参与度 | 按 [AI辅助开发说明](AI辅助开发说明.md) 从容应对 |
| 时间超时 | 优先砍场景演示细节，保留架构和创新点讲解 |
