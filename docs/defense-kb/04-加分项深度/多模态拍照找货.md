# 多模态拍照找货

> 评委问："拍照找货怎么实现的？图像怎么变成商品推荐的？" → 此页

## 加分项等级：⭐⭐⭐ 拍照找货

## 端到端链路（四层打通）

```
① Android Camera
   拍照/相册选图 → Uri → tempFile
   → POST /api/v1/upload/vision-search (multipart/form-data)
   │
   ▼
② VLM 图像理解
   Doubao-Seed-2.0-lite Vision API
   输入: 商品照片
   输出: product_info {description, category, attributes, color, style}
   代码: apps/backend/app/services/image_parser.py
   │
   ▼
③ RAG 相似商品检索
   提取的属性 → BGE Embedding → Qdrant 语义检索 (top_k=3)
   代码: apps/backend/app/services/retriever.py
   │
   ▼
④ SSE 流式返回
   event: vision_parsed (VLM 识别结果)
   event: product_cards (相似商品卡片)
   event: done
```

## VLM 输出结构示例

```json
{
  "description": "白色圆领短袖T恤，胸前有蓝色字母印花",
  "category": "服装",
  "attributes": ["白色", "圆领", "短袖", "棉质", "印花"],
  "style": "休闲"
}
```

## 降级策略

| 场景 | 降级 |
|------|------|
| VLM 识别失败 | 提示"请手动描述商品特征" |
| VLM 超时 | 30s 超时 → 降级提示 |
| 检索结果 < 25% | 告知用户"未找到相似商品" |
| 图片格式不支持 | 400 + 支持格式列表 |

## 与纯文本检索对比

| 维度 | 拍照找货 | 纯文本检索 |
|------|---------|-----------|
| 输入 | 无需描述，拍照即可 | 需手动输入关键词 |
| 覆盖属性 | 颜色/款式/材质/风格自动提取 | 依赖用户自行描述 |
| 用户体验 | 看到喜欢的直接拍 | 需想好怎么描述 |

## 路由实现

- 上传路由：`apps/backend/app/api/upload.py`
- Vision 路由：`/api/v1/upload/vision-search`
- Agent 节点：`node_vision_search` (agent.py)
