# 购物车闭环

> 评委问："购物车怎么做的？下单流程完整吗？" → 此页

## 加分项等级：⭐⭐⭐ 下单确认流程

## 功能矩阵

| 功能 | 难度 | 状态 |
|------|:--:|:--:|
| 对话式加购 | ⭐ | ✅ "把这个加到购物车" |
| 购物车管理（自然语言 CRUD） | ⭐⭐ | ✅ "删除第二个" / "数量改成 2" |
| 下单确认流程 | ⭐⭐⭐ | ✅ 汇总展示 → 确认下单 → 订单生成 |

## 完整对话流程

```
用户: "把刚才那款加到购物车"
  → intent: cart_operation, action: add
  → cart_service.add_to_cart() → PostgreSQL 写入
  → Agent 回复: "已为您将 Sony WH-1000XM5 加入购物车"

用户: "查看购物车"
  → intent: cart_operation, action: view
  → cart_service.get_cart() → 返回购物车列表
  → Agent 回复 + SSE cart_update 事件 → Android CartScreen 更新

用户: "删掉第二个"
  → intent: cart_operation, action: remove, item_index: 2
  → 自然语言序号解析（"第二个" → item_index=1）
  → cart_service.remove_from_cart()

用户: "下单"
  → intent: cart_operation, action: checkout (is_confirm=false)
  → 展示订单汇总: 商品列表 + 合计金额 + "确认下单？"

用户: "确认下单"
  → intent: cart_operation, action: checkout (is_confirm=true)
  → order_service.create_order() → 生成订单号 → 清空购物车
  → Agent 回复: "下单成功！订单号: ORD-2026-..."
```

## 后端实现

| 模块 | 文件 | 职责 |
|------|------|------|
| CartService | `apps/backend/app/services/cart_service.py` | 购物车 CRUD (PostgreSQL) |
| OrderService | `apps/backend/app/services/order_service.py` | 订单创建/查询 |
| Cart API | `apps/backend/app/api/cart.py` | RESTful 接口 |
| Order API | `apps/backend/app/api/order.py` | 订单接口 |
| Agent 节点 | `apps/backend/app/services/agent.py` — node_cart | 对话式购物车操作 |

## Android 实现

| 模块 | 说明 |
|------|------|
| CartScreen | 购物车列表 + 数量修改 + 删除 |
| CheckoutScreen | 订单确认弹窗（商品汇总 + 地址 + 金额） |
| CartViewModel | StateFlow 状态管理，实时同步后端 |

## 关键技术点

- **自然语言序号解析**："第二个" / "最后那个" / "Sony那款" 均能正确匹配
- **多商品批量操作**：支持一次删除/修改多个商品
- **2 步下单确认**：先展示订单汇总 → 用户确认 → 执行下单（防误操作）
- **事务安全**：下单成功后才清空购物车，失败则保留
