# 部署与可维护性

> 评委问："怎么跑起来？能自己部署吗？测试充分吗？" → 此页

## 一键部署

```bash
git clone git@github.com:fujunye-company/rag-ecommerce-agent.git
cd rag-ecommerce-agent
./deploy.sh              # 启动全部服务
./deploy.sh --build      # 启动 + 强制重建
```

脚本自动完成：
- Docker Compose 启动 Postgres + Qdrant + FastAPI
- 健康检查轮询（3 容器全部 healthy 才就绪）
- 已运行检测（避免重复启动）
- 首次启动自动导入 287 条种子数据
- HF 镜像加速 Embedding 模型下载

## Docker Compose 编排

```yaml
# infrastructure/docker-compose.yml
services:
  postgres:    # PostgreSQL 16 + pgvector
  qdrant:      # Qdrant 向量数据库
  backend:     # FastAPI :8080
```

## 可维护性措施

| 措施 | 说明 |
|------|------|
| 环境隔离 | `.env.example` → `.env` 多环境配置 |
| 安全 | API Key 纳入 `.gitignore`，不提交仓库 |
| 日志 | Python logging 分级（DEBUG/INFO/WARNING/ERROR） |
| 全局异常 | FastAPI exception_handlers 统一错误响应 |
| CORS | 跨域配置支持 Android 客户端访问 |
| 依赖锁定 | `requirements.txt` 精确版本 |
| CI 骨架 | `.github/workflows/` 预留 CI 配置 |

## 评委体验路径

1. 安装 APK：`apps/android/app/build/outputs/apk/debug/app-debug.apk`（24.1MB）
2. 启动后端：`docker compose up -d`
3. 配置地址：APK 中填入 `http://<server-ip>:8080`
4. 体验 9 场景：推荐 → 筛选 → 追问 → 对比 → 反问 → 反选 → 场景化 → 购物车 → 拍照找货

> APK 为预编译 Debug 版本，无需 Android Studio 即可直接安装体验
