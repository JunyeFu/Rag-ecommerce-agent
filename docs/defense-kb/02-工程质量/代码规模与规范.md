## 全栈数据契约（DATA-CONTRACT v1.0）

```python
# 后端 Pydantic Schema
class ProductCard(BaseModel):
    product_id: str
    title: str
    price: float
    image_urls: list[str]
    category: str
    brand: str
    score: float
```

```kotlin
// Android Data Class
data class ProductCard(
    val productId: String,
    val title: String,
    val price: Double,
    val imageUrls: List<String>,
    val category: String,
    val brand: String,
    val score: Double
)
```

> 字段类型、命名映射（image_urls ↔ imageUrls）全链路对齐
