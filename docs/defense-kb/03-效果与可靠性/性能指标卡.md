## 核心延迟指标

| 指标 | 目标 | 实测 | 状态 |
|------|:---:|:---:|:--:|
| 首 SSE 事件延迟 | ≤200ms | **47ms** | ✅ |

| 端到端延迟 | ≤15s | **~11s** | ✅ |
| 流式速率 | — | **>20 tok/s** | — |

## 检索性能

| 指标 | 数值 | 说明 |
|------|:---:|------|
| BGE Embedding | **~80ms** | 1024-dim 文本向量化 |

## 优化手段

| 手段 | 效果 |
|------|------|
| LRU 查询缓存 | 高频查询 12s → 16ms（**750x**） |
| Reranker lifespan 预热 | 消除首次 2s 冷启动 |
| Doubao thinking=disabled fast path | 意图/槽位分类从关键词规则 → LLM |
| 异步流水线 | 意图分类 + 检索并行执行 |
