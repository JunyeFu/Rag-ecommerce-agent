## 反幻觉三层防护

```
① Prompt 禁止清单
   禁止编造：商品名称/型号/价格/优惠券/满减折扣/赠品/认证标识/评价/排名
   只能引用 [1][2]... 标记的真实商品

② 检索结果校验层 (_validate_ranked_products)
   过滤：缺失 title/product_id 的记录
   过滤：价格为 0 或负数的无效数据
   匹配度 < 25% → 强制告知用户"当前没有很匹配的商品"

③ 编号引用强制
   LLM 回复必须标注 [1] [2] 编号
   未标注的推荐视为无效
```

## 生成质量保障

- **结构化输出**：LLM 生成 `[SUMMARY]` / `[PRODUCT_N]` / `[CLOSING]` 三段式
- **匹配度标注**：每款商品标注匹配度百分比
- **推荐理由**：每款商品给出 1-2 句推荐理由（来自 highlights 字段）
- **缓存版本校验**：CACHE_VERSION 防过期数据输出
