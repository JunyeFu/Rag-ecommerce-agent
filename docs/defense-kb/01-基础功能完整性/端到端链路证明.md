# 端到端链路证明

> 评委问："从用户发消息到看到回复，完整链路怎么走的？" → 此页

## 核心链路（8步）

```
用户输入 "推荐降噪耳机"
  │
  ▼
① ChatInputBar (Android Compose)
  → ChatViewModel.sendMessage()
  → POST /api/v1/chat
  → 路由: apps/backend/app/api/chat.py
  │
  ▼
② LangGraph Agent (agent.py:3049行)
  → node_classify_intent: 意图分类 + 槽位提取
    代码: apps/backend/app/services/intent.py (16740行)
    输出: intent=commodity_recommend, category=耳机, feature=降噪
  │
  ▼
③ node_retrieve: Qdrant 向量检索
    代码: apps/backend/app/services/retriever.py (218行)
    Embedding: BGE-large-zh-v1.5 (1024-dim)
    延迟: ~15ms (检索) + ~80ms (Embedding)
  │
  ▼
④ node_rerank: BGE-Reranker-v2-m3 精排
    代码: apps/backend/app/services/reranker.py (151行)
    延迟: ~900ms
  │
  ▼
⑤ node_rank: 多维加权排序
    代码: apps/backend/app/services/product_ranker.py
    权重: 语义40% + 价格20% + 评分15% + 品牌10% + 属性15%
  │
  ▼
⑥ node_generate: LLM 生成推荐回复
    代码: apps/backend/app/services/agent.py — node_generate
    LLM: Doubao-Seed-2.0-lite
    格式: [SUMMARY] + [PRODUCT_1]...[PRODUCT_3] + [CLOSING]
    延迟: ~1.5s (TTFT)
  │
  ▼
⑦ SSE 流式输出（8 事件类型）
    格式: progress → text_delta → product_cards (交错) → done
    首事件延迟: 47ms
    代码: apps/backend/app/api/chat.py — event_generator
  │
  ▼
⑧ Android 流式渲染
    SseClient (OkHttp) → callbackFlow → ChatViewModel → ChatScreen
    组件: StreamingBubble + ProductCard
    代码: apps/android/.../data/remote/SseClient.kt
          apps/android/.../viewmodel/ChatViewModel.kt
```

## 全链路延迟

| 环节 | 延迟 | 说明 |
|------|:---:|------|
| 意图分类 | ~200ms | LLM 调用 |
| BGE Embedding | ~80ms | 文本向量化 |
| Qdrant 检索 | ~15ms | COSINE top-10 |
| Reranker 精排 | ~900ms | BGE-Reranker-v2-m3 Cross-Encoder |
| LLM 首 Token (TTFT) | ~1.5s | Doubao streaming first chunk |
| LLM 完整生成 | ~8s | 含 streaming |
| 端到端 | **~11s** | 用户发消息→完整回复 |

## 关键证据：SSE 事件流

后端推送事件序列（交错格式）：
```
event: progress          →  "正在分析需求..."
event: text_delta        →  "为您推荐以下几款降噪耳机："
event: product_cards     →  [{id, title, price, image_urls, score}]
event: text_delta        →  "[1] Sony WH-1000XM5..."
event: product_cards     →  [{id, title, price, image_urls, score}]
event: text_delta        →  "以上三款都是目前降噪耳机中的热门选择..."
event: done              →  {total_cards: 3, latency_ms: 11000}
```

## 多模态链路（拍照找货）

```
Camera(Uri) → tempFile → POST /api/v1/upload/vision-search
  → Doubao Vision API 图像理解
  → product_info {description, category, attributes}
  → Qdrant 相似商品检索 (top_k=3)
  → SSE: vision_parsed | product_cards | done
```
