# 数据工程

> 评委问："数据怎么来的？怎么入库的？检索怎么做的？" → 此页

## 数据规模

| 指标 | 数值 | 比赛要求 |
|------|:---:|:---:|
| 商品总数 | **287** | 50-100 |
| 品类数 | **94** | 不限 |
| 单商品字段 | title, description, price, brand, category, highlights, image_urls | — |
| 向量维度 | 1024 | bge-large-zh-v1.5 |

## 数据来源

- 种子数据脚本：`apps/backend/app/data/qdrant/seed_data.py`
- 数据文件：`products_expanded_100.jsonl`
- 入库方式：Docker 首次启动自动调用 `ensure_qdrant_data()`

## Chunking 策略

| 策略 | 值 |
|------|-----|
| 粒度 | 商品级（每商品一个 chunk） |
| Embedding 模型 | BAAI/bge-large-zh-v1.5 |
| 向量维度 | 1024 |
| Qdrant 集合名 | `products` |
| Point ID | UUID5 确定性生成（title + category → UUID） |

## 双库协同

```
PostgreSQL                        Qdrant
┌──────────────────┐         ┌──────────────────┐
│ products 表       │  UUID5  │ products 集合     │
│ - id (UUID)      │◄───────→│ - id (UUID5)      │
│ - title          │  同步   │ - vector (1024)   │
│ - price          │         │ - payload (JSON)  │
│ - brand          │         │   title/price/... │
│ - category       │         │   image_urls/...  │
│ - highlights[]   │         └──────────────────┘
│ - image_urls[]   │
└──────────────────┘
```
