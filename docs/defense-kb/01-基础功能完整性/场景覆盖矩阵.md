## 逐场景关键实现

### 场景 1：单轮模糊推荐
- 输入示例："推荐适合油皮的洗面奶"
- 链路：意图识别(intent.py) → Qdrant 语义检索(retriever.py) → Reranker 精排 → LLM 三段式推荐(agent.py)
- 输出：SSE text_delta + 3 product_cards + done

### 场景 2：条件筛选
- 输入示例："200元以下的蓝牙耳机有哪些？"
- 关键：LLM 槽位提取 price_max=200, category=耳机 → Qdrant 范围过滤 → 0结果分级回退
- 代码路径：`apps/backend/app/services/intent.py` — classify_intent 函数

### 场景 3：多轮追问
- 输入链："推荐耳机" → "要降噪好的" → "300以内"
- 关键：PostgreSQL sessions 表持久化对话状态，品类上下文继承，切换品类自动重置偏好
- 代码路径：`apps/backend/app/services/state_manager.py`

### 场景 4：对比决策
- 输入示例："华为和韶音耳机哪个更适合跑步"
- 关键：多商品并行检索 → 多维属性提取 → LLM 对比总结 + 维度可视化
- 代码路径：`apps/backend/app/services/comparator.py`

### 场景 5：Agent 主动反问
- 输入示例："推荐一款手机" → Agent："更看重拍照、续航还是性价比？"
- 关键：LangGraph clarify 节点 → ClarifyEvent SSE → Android 反问 UI 渲染
- 代码路径：`apps/backend/app/services/agent.py` — node_clarify

### 场景 6：反选排除
- 输入示例："推荐防晒霜，不要含酒精的，不要日系品牌"
- 关键：意图层否定提取 → Qdrant must_not 过滤 → 文本级兜底
- 验证：5 组反选查询 100% 排除率
- 代码路径：`apps/backend/app/services/exclusion_rules.py`

### 场景 7：场景化组合推荐
- 输入示例："下周三亚度假，防晒到穿搭方案"
- 关键：LLM 动态品类映射（94品类中选3-5个） → 品类感知 MMR 采样 → 场景感知 Prompt → ScenarioEvent SSE
- 代码路径：`apps/backend/app/services/agent.py` — node_retrieve (scenario 分支)

### 场景 8：购物车闭环
- 链路：对话式加购 → CRUD → 下单确认 → 订单生成
- 代码路径：`apps/backend/app/services/cart_service.py` + `order_service.py` + `apps/backend/app/api/cart.py`

### 场景 9：拍照找货
- 链路：Camera → VLM (Doubao Vision) → 属性提取 → Qdrant 相似检索 → SSE 商品卡片
- 代码路径：`apps/backend/app/services/image_parser.py` + `apps/backend/app/api/upload.py`
