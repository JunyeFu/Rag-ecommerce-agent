# V3 project-authored demo catalog

This directory contains deterministic fictional products, offers and SVG illustrations generated by `scripts/generate_demo_catalog.py`.

- No record represents a real product, merchant, price, inventory or affiliate authorization.
- `DEMO_FIXTURE` may be used only for local demonstrations and automated tests.
- The legacy 287-row development seed and its images are not copied into this distributable demo dataset.
- Regenerate with `uv run python scripts/generate_demo_catalog.py`; verify with `--check`.
